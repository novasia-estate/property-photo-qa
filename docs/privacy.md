# Private review workflow

Work from a dedicated folder you are authorised to inspect. Set your actual publishing thresholds, supply an optional property mapping, generate a report and review individual findings. Resolve problems in your source workflow, then run a new audit. Never publish a report containing client photos without permission.

No file is stripped, renamed or deleted by this tool. GPS presence is a warning; removing GPS from a future publication copy is a separate owner-controlled action. File names and property IDs can themselves identify a client. Do not attach private reports to public issue trackers. Byte hashes do not establish authenticity, rights or image ownership.
